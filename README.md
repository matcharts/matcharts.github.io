# Matcharts.ca

Site vitrine réalisé pour **Mat Charts**, DJ et producteur basé à Montréal.  
L’objectif du site est de présenter son univers musical, ses événements et d’offrir un moyen simple de le contacter pour des prestations.

## Description

Le site met en avant :  
- Une page d’accueil claire et immersive  
- Une section **À propos** pour découvrir l’artiste  
- Des témoignages et retours d’expérience  
- Des liens directs vers ses réseaux sociaux  
- Un moyen de **prendre contact / réserver** facilement  

L’accent a été mis sur un design moderne, une navigation simple et une bonne lisibilité sur mobile comme sur ordinateur.
